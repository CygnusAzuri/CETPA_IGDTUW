## 🔄 Typical AIML Workflow

The practical projects helped me understand how an ML project can move from raw data to a final prediction:

```text
Dataset
   ↓
Data Understanding
   ↓
Data Cleaning
   ↓
Preprocessing
   ↓
Exploratory Data Analysis
   ↓
Feature Selection / Preparation
   ↓
Model Training
   ↓
Prediction
   ↓
Model Evaluation
```
