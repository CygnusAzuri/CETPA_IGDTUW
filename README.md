This project is implemented using **Google Colab** and Python. It demonstrates the complete workflow of the project, including data loading, preprocessing, analysis/model development, evaluation, and visualization.

The dataset is processed through the following steps:

2. Checking the dataset structure.

## 🚀 How to Run

1. Open the provided Google Colab notebook.
2. Connect to a runtime.

5. Observe the generated outputs, graphs, and results.

